# ELARED Report System — Instrucciones para Claude Code

Al final de cada tarea completada en este repo, siempre ejecutar:

```
git add .
git commit -m "feat/fix: [descripción breve del cambio]"
git push origin master
```

Así el repositorio siempre está actualizado y puede trabajarse desde
cualquier PC. Confirmar que el push fue exitoso antes de dar la tarea
por terminada.
